Timestamp Converter

Convert a Unix timestamp to a readable date, or a date to a timestamp. The unit is guessed from the size of the number and the guess is always shown.

A bare integer does not say what unit it is in, so the size of the number decides: ten digits is read as seconds and thirteen as milliseconds. The reading is always shown, and the dropdown overrides it. Local times use this device's timezone, which is what the picker means when you type into it.
