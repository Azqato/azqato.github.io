# Old Website — azqato.com

This directory is an archival recreation of the original Azqato website, which was built on **Google Sites** and hosted at `azqato.com`. The goal is to preserve the original site as a static HTML/CSS/JS build before the domain is migrated to the new GitHub Pages portfolio.

## Purpose

- Preserve the original site's content, design, and functionality
- Serve as a reference for the domain migration
- Provide a self-contained fallback that does not depend on Google Sites infrastructure

## Tech Stack (Rebuild Target)

- Vanilla HTML5
- Vanilla CSS3
- Vanilla JavaScript (ES6+)
- Zero external dependencies
