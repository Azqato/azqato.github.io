- [ ] 50. **text** [main]: TQQQ
- [ ] 51. **text** [main]: uses daily rebalancing to deliver 3x the daily return of the Nasdaq-100. This daily reset means returns compound on a daily basis, not over longer periods. In volatile, sideways markets this creates volatility decay: the fund can lose value over time even when the index itself is flat or modestly positive. Drawdowns are amplified and recoveries take proportionally longer. These characteristics apply to every strategy documented here.
